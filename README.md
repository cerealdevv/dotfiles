# dotfiles
cereal's dotfiles, planned to be used in MiraOS

## dependencies
hyprland:
 - slurp
 - grim
 - wl-clipboard
 - hyprlauncher
 - kitty
 - dolphin
all of the above are OPTIONAL dependencies, it will work without them, but for the full experience
they're reccomended.

## installation
for a full config replacement, clone this repository and move all files to `~/.config`
for noctalia to look correct, you will also need to manually apply the wallpaper in
`~/.config/noctalia/assets/arch_wallpaper.png`.
